# Système de Facturation – PHP (MVC)
Ce projet est un système complet de gestion de facturation, développé en PHP avec un framework MVC personnalisé.
Il permet de gérer les patients, les prestations, les montants associés, et de générer des factures de manière rapide, fiable et organisée.

Ce logiciel a été conçu pour un environnement professionnel, notamment dans le secteur médical.
